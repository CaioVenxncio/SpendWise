# 📊 SpendWise — Personal Expense Tracker

A simple **personal finance tracking** app developed in Flutter. Allows users to manage their daily expenses easily and quickly.

---

## ✨ Features (MVP 1.0)

* Add expenses (amount, description, category, date)
* List registered expenses
* Delete expenses
* Display the total expenses for the current month
* Local storage using `shared_preferences`

---

## 🛠 Technologies Used

* **Flutter** 3.0+
* **State Management:** `setState()`
* **Local Storage:** `shared_preferences`
* **Design:** Material Design

---

## 💻 How to Run the Project

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/spendwise.git
```

### 2️⃣ Navigate to the project directory

```bash
cd spendwise
```

### 3️⃣ Install dependencies

```bash
flutter pub get
```

### 4️⃣ Run the app

```bash
flutter run
```
